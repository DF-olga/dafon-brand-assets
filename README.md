## 下載
請到右側 **Releases** 下載最新版的 `DaFon_Brand_Assets_版本_日期.zip`（不是 Source code）。

| 07_Logo品牌標誌 | SVG 標誌 10 個 |

## 使用原則
- 標誌一律使用 07 資料夾的 SVG 原始檔，不可重繪或由 AI 生成。
- 公司數字與事實只引用《大豐環保公司資料庫.md》。
- 詳細規則見《大豐品牌規範.md》。
